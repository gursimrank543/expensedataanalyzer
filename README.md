# Expense Data Analyzer 
C++ application for recording and analyzing expense data.

##Features

-Record multiple expenses
-Calculate total spending 
-Calculate average expense
-Analyze spending by category
-Find highest and lowest expenses
-Search expenses by category
-Sort expenses from highest to lowest
-Validate expense amounts
-Save expense data to a CSV file
-Load expense data from a CSV file

##Technologies

-C++ 
-STL `vector`
-STL `map`
-File I/O
-CSV data handling
-Sorting algorithms
-Input validation

##How to Run

Compile the program: 

```bash
g++ main.cpp -o expensedataanalyzer.exe
